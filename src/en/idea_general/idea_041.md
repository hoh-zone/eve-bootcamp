# 41. Evolving Tamagotchi Drones

## 💡 Core Concept (Concept)
A very fragile electronic eye NFT that exists in the cargo bay of a starship. Players must feed it specific fuel dregs on time every day. If they forget to feed it for 7 days, its happiness value metadata will return to zero and it will automatically dissipate from space. If raised well, it provides a weak but useful mining buff to the entire ship.
