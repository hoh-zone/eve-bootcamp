# 34. Seamless hot update package manager (Upgradable Package Manager)

## 💡 Core Concept (Concept)
Since modifying immutable assets is extremely risky, design a pluggable modular gateway. When it is necessary to iterate the gateway AI or charging logic in the future, the entry pointer of the smart component can be mapped to the newly released Package, and the tens of billions of materials stored in it do not need to be migrated.
